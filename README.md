dir: Lists files and folders in the current directory.
cd: Changes the current directory (e.g., cd .. moves up one folder).
ipconfig: Displays network configuration, useful for finding your IP address.
ping: Tests network connectivity by sending packets to a website or IP.
mkdir / md: Creates a new directory or folder.
del / erase: Deletes one or more files.
tasklist: Displays all currently running processes.
taskkill: Terminates a running process (e.g., taskkill /IM notepad.exe /F).
systeminfo: Displays detailed configuration, OS, and hardware information.
cls: Clears the command prompt screen. 
copy / move: Copies or moves files between folders.
ren: Renames files or directories.
chkdsk: Checks a disk for errors and repairs them.
shutdown /s /t 0: Shuts down the computer immediately.
help [command]: Displays information about a specific command.
